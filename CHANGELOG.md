# Версии макета

Каждый тег `mockup-vX.Y.Z` соответствует версии, опубликованной на GitHub Pages. Описание ниже также публикуется в GitHub Releases.

## mockup-v0.1.1

- Для техники тип теперь можно сбросить кнопкой в поле выбора или пунктом «Не указан».
- Отсутствующий тип сохраняется как `null`; старые пустые значения автоматически приводятся к нему.

## mockup-v0.1.0

Первый публичный выпуск интерактивного макета «Аврора Агро».

- Операции, поля, севооборот, отчёты и отдельные страницы справочников.
- Добавление техники из корневого проекта, выбор одного из семи типов или пустого типа.
- Страница техники с настройкой положения трекера в метрах и сантиметрах.
- Оформление по дизайн-системе Aurora, светлая и тёмная темы.
- Публикация GitHub Pages по тегам с отображением версии в макете.
